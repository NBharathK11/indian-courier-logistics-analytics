# Indian Courier & Logistics Performance Analytics

## Overview

End-to-end courier and logistics data analysis project focused on shipment volume, revenue, delivery performance, and operational insights.

## Tools & Technologies

- Python
- Pandas
- NumPy
- SQL Server
- Power BI
- DAX
- Statistics

## Project Workflow

Python Data Cleaning & EDA → SQL Server Analysis → Power BI Dashboard

## Dataset

The project uses a synthetic Indian courier/logistics dataset containing 49,639 shipment records.

## Key Analysis

- Shipment volume by delivery mode
- Revenue and shipment value analysis
- Delivery performance analysis
- Value Added Services revenue
- Payment method analysis
- City and route-level analysis
- Monthly revenue trends
- Weight and pricing analysis

## Dashboard

An interactive Power BI dashboard was developed using DAX to analyze business performance, revenue contribution, delivery efficiency, and operational trends.

## Project Files

- `dtdc_python.ipynb` — Python cleaning, EDA and analysis
- `dtdc_logistics_analytics.sql` — SQL Server queries and analysis
- `dtdc_logistics_analytics.pbix` — Power BI dashboard
- `dtdc_logistics_cleaned.csv` — Cleaned dataset
